# Changelog

All notable changes to Aquarela are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com) and versions follow
[Semantic Versioning](https://semver.org).

## [Unreleased]

### Added

- Design doc.
- Web app with the image canvas. It supports pan, zoom, boxes, classes and
  moving between images.
- API and data model for v0.1.
- Roadmap.

### Changed

- Release workflow actions updated to versions that run on Node.js 24.

## [0.0.2] - 2026-10-25

### Added

- Release workflow that publishes to PyPI, npm and crates.io with Trusted
  Publishing.

## [0.0.1] - 2026-10-24

### Added

- Placeholder packages that reserve the name on PyPI, npm and crates.io.
