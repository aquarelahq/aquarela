# Aquarela

Paint, draw and label freely. Your data never leaves your machine.

Aquarela is an open source data labeling tool. It runs local first, syncs through a server you host yourself, and works with any AI model. No paid tiers, no locked features.

Early development. See the [roadmap](ROADMAP.md) for what comes next and
[CONTRIBUTING.md](CONTRIBUTING.md) to propose ideas or report bugs.
